# Tatami Galaxy Explorer

A 3D interactive universe visualization inside a Japanese tatami room.

## Controls

- **Drag** - Orbit camera around the scene
- **Scroll** - Zoom in/out
- **Click** on celestial bodies - View info panel and focus camera
- **Close panel** - Return to normal view

## Buttons

- ** Night / Day** - Toggle day/night mode
- ** Top View /  Side View** - Toggle camera perspective
- ** Sound On /  Sound Off** - Toggle ambient audio
- ** Reset** - Reset camera to default view

## Features

- 8 celestial bodies (planets, stars, moon, black hole, nebula)
- Asteroid belt
- Comet with tail
- Shooting stars
- Auto-orbit when idle

## Tech

- Three.js (via CDN)
- Pure JavaScript, no build required
